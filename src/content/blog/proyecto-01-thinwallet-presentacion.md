## Enunciado
Presentar ThinWallet como nuestro proyecto y explicar su objetivo dentro del apartado de proyecto.

## Contexto
ThinWallet es un sistema para gestionar finanzas personales y gastos compartidos. El objetivo es ayudar a usuarios y grupos a registrar movimientos, organizar deudas, analizar reportes y mantener trazabilidad de la actividad financiera.

## Que resuelve ThinWallet
1. Registro de usuarios y circulos de gasto.
2. Control de ingresos, egresos, deudas y pagos.
3. Auditoria de acciones importantes.
4. Analitica para ver estados de cuenta, circulos y tendencias.

## Arquitectura del proyecto
- **MySQL** para el modelo relacional principal.
- **MongoDB** para auditoria y eventos con estructura flexible.
- **Procedimientos, funciones, triggers e indices** para automatizar reglas de negocio.

## Explicacion
ThinWallet no es solo una base de datos: es una solucion pensada para organizar el dinero de forma clara, compartir gastos entre personas y obtener reportes utiles sin perder trazabilidad.
